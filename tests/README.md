## Os testes
Vc validar o algoritmo do SafeWeb contra todas as URLs depois documentandar tudo

## como executar os testes

No terminaldo projeto e so executar:

```bash
npm test
```
*(ou `node tests/url-tests.js`)*

## estrutura dos casos de Teste

os teste estão cadastrados no arquivo `test-cases.json`

### Como Adicionar Novos Testes:
abrir `tests/test-cases.json` e adiciona novos objetos no array com as URLs a serem validadas
